인증 평가 방식

실기 시험 3시간
10~15문제, 최대 20문제, 평균 13~15문제
각 분야별로 2~3문제 정도 (비전, 언어, RAG, 데이터, On-device)
교안에 포함된 내용만 문제로 나옴
문제 마다 배점 다르고 부분 점수 존재
이전 문제 종속성 없음

문제 유형
- 주어진 출력값이 나오도록 코드 작성
- 강의나 교안 내용과 다르게 구현해도 정답 인정

1. 코드에 마스킹돼있는 부분을 채워넣는 방식
  - ### 작성 필요 ### : 필요한 코드  작성
  - 라인 일부 작성 아니고 라인 전체 작성해야하는 방식인 듯
2. 코드 내부에 함수 구현
  - ### 공개 제한 ### : 강의 교안에 정답 부분이 reference 문서 상에서는 `공개 제한`으로 가려짐
  - 함수 구현 문제는 reference 문서에서 `공개 제한` 부분 외에는 그냥 가져오는게 편한 듯
