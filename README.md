# AIS 실기 연습실

레포의 **ipynb 코드만** 근거로 만든 로컬 퀴즈 앱입니다. PDF의 출제 포인트와 `인증평가유형.txt`를 기준으로 코드 줄·블록 완성과 함수 구현을 연습합니다. 사용자 요청으로 **KV Cache Pruning과 Speculative Decoding**을 추가했습니다. 원본 자료는 변경하지 않습니다.

## 실행

Python 3.9~3.12 기준입니다. 이 작업 환경에는 CPU 실행용 패키지를 `.quiz-deps/`에 준비했습니다.

```bash
./run_quiz.sh
```

브라우저에서 **http://127.0.0.1:8765** 에 접속합니다. 포트를 바꾸려면 `./run_quiz.sh --port 8766`을 사용합니다. 종료는 `Ctrl+C`입니다.

### 핸드폰에서 풀기 (GitHub Pages)

`docs/`에는 서버 없이 동작하는 객관식 전용 페이지가 들어 있습니다. 변경사항을 GitHub의 `main` 브랜치에 push한 뒤 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 설정하면 `https://wsoarc.github.io/AIS/`에서 접속할 수 있습니다. 진행 기록과 최근 오답은 핸드폰 브라우저에 저장됩니다.

문제은행을 수정한 뒤에는 아래 명령으로 Pages 데이터를 다시 생성합니다.

```bash
PYTHONPATH=.quiz-deps python3 -m quiz_app.export_pages
```

다른 환경에서 처음 실행할 때는 가상환경 또는 프로젝트 전용 경로에 설치하세요. 모델·데이터 다운로드나 API 키는 필요하지 않습니다.

```bash
# 가상환경을 사용할 수 있는 환경
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r quiz_app/requirements.txt
./run_quiz.sh

# venv/ensurepip가 없는 환경의 대안
python3 -m pip install --target .quiz-deps -r quiz_app/requirements.txt
./run_quiz.sh
```

서버·객관식에는 Python 표준 라이브러리만 필요합니다. 실행 패키지가 없으면 화면에 설치 안내를 표시하고 주관식 채점은 **보류**합니다. 패키지 오류나 실행 시간 초과를 오답으로 처리하지 않습니다.

## 사용

- **객관식:** 주변 구현을 제공하고 핵심 1~2줄만 빈칸으로 둡니다. 보기에는 그 빈칸에 들어갈 짧은 코드만 표시하며, 전체 함수를 반복하지 않습니다. 채점 후에도 빈칸 정답을 보여 줍니다.
- **학습 모드:** 분야 복수 선택, 객관식/주관식/혼합, 쉬움/보통/어려움/전체, 문제 수 선택. 즉시 채점·힌트·해설을 제공합니다.
- **모의시험:** 180분, 20문항, 분야별 4문항, 난이도 혼합. 문제 유형은 선택할 수 있습니다. 답안만 저장하다 종료 후 일괄 채점합니다. 시간이 지나면 마지막 저장된 답안으로 자동 종료합니다.
- **주관식:** 제공된 바깥 함수·클래스 선언을 반복하지 않고 `### 작성 필요 ###` 구간의 **코드 전체 줄 또는 내부 블록**만 작성합니다. 클래스 내부가 가려진 문제는 필요한 메서드 정의도 작성합니다. 첫 줄의 기본 들여쓰기는 자동 적용하며 중첩 블록의 상대 들여쓰기는 유지해야 합니다. Tab은 공백 4개, Ctrl+Enter는 제출입니다.
- **채점:** 작은 입력 3개로 실제 실행합니다. 결과·shape·dtype·일부 문제의 기울기나 호출 흐름을 비교합니다. 수치 허용 오차는 rtol=1e-5, atol=1e-6입니다. 검증 입력별 동일 비중으로 부분 점수를 부여합니다. 쉬움 5점, 보통 10점, 어려움 15점은 **앱 자체 배점**입니다.
- **오답 복습:** 브라우저의 최신 시도에서 미정답인 문제만 모아 다시 풉니다. 학습 기록은 localStorage에 최대 1500개 저장되며 외부로 전송하지 않습니다.
- **저장:** 풀이 중 입력은 브라우저와 실행 중인 서버에 저장됩니다. 새로고침 후 계속 풀 수 있습니다. 서버를 재시작하면 진행 중인 세션은 복구되지 않지만 브라우저 학습 기록은 유지됩니다.
- **노트북 저장:** 현재 퀴즈와 작성한 답안을 `.ipynb`로 내려받아 따로 실행할 수 있습니다. 미작성 문제는 마스킹을 채워야 실행됩니다. 이 파일은 실행 연습용이며 앱의 자동 채점기는 포함하지 않습니다.

## 출제 근거와 현재 범위

총 **86문항**이며 기본 유형은 객관식입니다. 다섯 summary의 코드가 있는 주제를 실제 노트북에서 발췌하고, 데이터·모델·학습·검색 흐름으로 묶었습니다. 객관식과 주관식 변환은 별도 문항으로 세지 않습니다.

| 분야 | 문항 수 | 주요 범위 |
|---|---:|---|
| LLM | 15 | Tokenizer, GPT·Attention·Embedding, 토큰 손실·생성, LoRA 초기화·동결 |
| Vision | 12 | CIFAR 전처리·데이터셋, ResNet, ViT 패치·Attention, U-Net 구성 |
| On-device | 22 | 양자화·QAT·AWQ·Rotation, 세 가지 KD, KV 보존 전략, Speculative·DFlash |
| Data | 19 | 시계열 분할·RNN 계열, 추천 전처리·Graph, NCF/NGCF 학습, 평가 지표 |
| RAG | 18 | 로딩·HTML·Chunk·Embedding, 검색·Reader, KG, MCP tools/resources·Agent, CRAG 평가 |

[출제 범위 문서](quiz_app/COVERAGE.md)에 summary 항목별 대응 문항과 원본 셀을 정리했습니다. 모든 세부 줄을 각각 빈칸으로 만들지는 않습니다. Instruction following/DPO·EAGLE은 summary의 패스 표시를 따르고, 코드가 없는 DETR 제목은 제외합니다.

기존 난이도와 배점은 유지합니다. 작은 CPU 입력과 외부 서비스 대체 객체로 실제 코드를 검증하며 필요한 설정과 인터페이스는 제공합니다. RAG 서비스나 모델을 다운로드하지 않습니다. NGCF 노트북의 집계 오타 교정은 문항 해설과 source에 기록합니다.

## 실행 경계

앱은 **자신의 컴퓨터에서 자신이 작성한 코드를 실행하는 연습 도구**입니다. 서버는 127.0.0.1에만 바인딩하며 Host/Origin과 요청 토큰을 확인합니다. 답안은 별도 프로세스, 임시 작업 디렉토리, 최소 환경 변수로 실행하고 20초 제한을 둡니다. 이는 완전한 보안 샌드박스가 아니므로 인터넷에 공개하거나 신뢰할 수 없는 사람의 코드를 실행하는 용도로 사용하지 마세요.

출제 정답은 서버 쪽에서 보관하고 풀이 API에는 미리 넣지 않습니다. 객관식 보기는 출제 때 섞습니다. 모의시험은 종료 전 채점·힌트 API를 차단합니다. 학습용 로컬 앱이므로 저장소의 정답 파일 자체를 열어 보는 행위를 막는 감독 시스템은 아닙니다.

## 검증과 구성

```bash
PYTHONPATH="${PWD}/.quiz-deps${PYTHONPATH:+:${PYTHONPATH}}" python3 -m unittest discover -s tests -v
```

검증은 모든 주관식 86개 정답·258개 오답 변형 및 객관식 86개 빈칸 정답·258개 짧은 오답 보기, 동등한 대체 구현, 부분 점수, 오류·시간 제한, 출제 비율, 시험 종료 전 정답 비공개, 자동 저장·만료를 확인합니다.

- `quiz_app/catalog.py`: 노트북 발췌, 마스킹, 보기, 해설, 출처와 실행 fixture
- `quiz_app/expansion.py`: 기존 문제를 보존한 PDF 중심 추가 문항
- `quiz_app/mcq.py`: 핵심 빈칸과 짧은 객관식 보기(주관식과 분리)
- `quiz_app/grading.py`, `worker.py`: 별도 프로세스 실행·동작 비교
- `quiz_app/server.py`: 로컬 API·세션·시험 관리
- `quiz_app/static/`: 외부 CDN 없이 작동하는 화면
- `tests/test_quiz.py`: 출제·채점·API 회귀 검증

새 문제는 `catalog.py`의 `add(...)`에 등록하고 기존 검증을 실행하세요. 원본 셀 구조가 달라지면 발췌에 실패할 수 있으므로 문제 근거와 채점을 다시 검수해야 합니다.
