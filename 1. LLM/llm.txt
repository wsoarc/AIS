AI 모델의 역사AlexNet : 딥러닝 성능 검증한 최초 모델 -> 깊은 layer를 위한 경쟁 돌입ResNet : Skip Connection을 도입해 깊은 layer에서 무너지는 문제 해결, ImageNet에서 사람과 동일한 성능Word2Vec : 단어의 의미를 벡터 공간에 맵핑, 단어 간의 연산을 가능하게 함 (추론)Alphago -> AlphaGo Zero -> AlphaZero : AI 모델의 범용화Transformers : Attention is all you needGAN & Diffusion : 멀티 모달 생성의 시작 GAN -> Diffusion 시대GPT : 규모의 시대, GPT-2 `1.5B` -> GPT-3 `175B`AlphaFold : 단백질 구조 예측 모델, 전통적 방식의 종말 (X선 결정학의 종말, 인공합성 단백질 시대)2. AI의 미래AI의 호황 : 에너지, 인력, 돈, 자원을 빨아들이는 AI, OpenAI IPO 규모 1 TRILLION USD...빅테크의 AI 투자 계획 : 4개 빅테크 회사들이 1년에 300억 달러 규모 투자World Model과 Physical AI -> 휴머노이드의 발전노동의 가치와 해방, 산업의 파괴 (Claude Cowork, Seedance 2.0 등등), 전쟁과 AI3. AI 기본 수학벡터- 스칼라 - 벡터(1D) - 매트릭스(2D) - 텐서(3D), 	텐서 입력 모양 - (B, C, E)- 내적 : 벡터 간의 유사도 계산(길이 까지 고려), Scalar 값, 반대방향 -, 같은방향 +, 직교하면 0- Cosine similarity : 의미적 방향의 유사도 (방향성만 고려), 단위 벡터에서는 내적과 동일행렬 : 요소별 곱셈(*), 요소별 덧셈(+), 행렬 곱셈(@), Transpose(T)선형함수 : layer를 통과한 값을 계산, y = f(x) = ax + b , z = w1x1 + ... + wnxn + b -> z = WTx + b경사하강법 : 실제값과 예측값의 차이를 최소화, Linear Regression, Gradient Descent, MSE = (1/N)Σ(yi - y^i)^2활성화함수 : 비선형성을 부여하여 복잡한 패턴 학습을 가능하게 함, 선형 함수 뒤에 활성화 함수 배치지수함수 : 작은 차이를 극적으로 확대, 모든 숫자를 양수로 변환로그함수 : 곱셈을 덧셈으로 변경 - 연산 속도 향상, 언더플로우 방지, 틀렸을 때 강력한 피드백을 줌, 자연로그를 미분하면 깔끔하게 1/x가 됨자연상수(e) : 모든 지수함수는 자연상수로 표현 가능, 미분했을 때 자기 자신이 나옴 - (d/dx)e^x = e^xSoftmax : 여러 출력값을 각각의 확률로 변환, 모든 확률의 합은 1, 다중 분류나 상호 의존성을 가진 활성화 함수에 사용Sigmoid : 입력값 z를 0과 1 사이의 확률로 변환, 이진 분류, 활성화 함수에 사용신경망 학습 : 크게 3단계- 1단계 : feedforward 순전파- 2단계 : loss 계산- 3단계 : backpropagation 역전파, chain rule을 이용하여 기울기 계산 후 모든 가중치 업데이트 (여기서 경사하강법 사용, learning late 관여)KL Divergence, Cross Entropy: 목표 확률과 현재 확률이 얼마나 유사한가?- Cross Entropy에서 실제 데이터 자체의 Entropy를 뺀 값이 클 수록 벌점Perplexity : 언어 모델이 다음 토큰을 얼마나 잘 예측하는지 측정하는 지표- PPL - Cross Entroph H를 자연상수 e의 지수로 변환한 값- 사람이 이해하기 직관적인 스케일- 값이 낮을수록 좋은 모델조건부확률베이즈정리4. 언어 모델의 발전규칙기반 번역 : 형태소 분석 -> 구문 분석 -> 변환 -> 규칙으로 어순 배열Encoders / Decoders : 입력을 이해하고 이해를 바탕으로 생성RNN : 히든 스테이드를 재귀적으로 반복, 가변길이 처리 가능하지만 길수록 앞 부분이 잊혀지고 마지막 정보만 뚜렷RNN Attention : 이전 단계의 입력 토큰을 참조, 번역 정확도 향상, 이전 은닉 상태 저장해야해서 메모리 증가, 순차처리만 가능(RNN도 마찬가지), Hidden에 다른 정보가 섞여있음Transformer- Attention과 병렬화 가능한 아키텍처가 핵심- Attention과 FeedForwardNetwork로 구성됨- Self Attention, Cross Attention 조합으로 Encoder, Decoder 구성- Encoder만 쓰는 모델 : BERT, T5	- Masked Language Model(MLM)	- 양방향 학습, 빈칸 채우기 문제, 양쪽 문맥 모두 참조 가능- Decoder만 쓰는 모델 : GPT	- Causal Language Model(CLM)	- 단방향 학습, 다음 단어 맞추기 문제, 앞쪽 문맥만 참조 가능5. 언어 모델 : 입력Tokenizer : 입력 문장을 의미 단위로 잘라서 고유번호 부여- BPE Tokenizer : 가장 많이 등장하는 쌍 찾아서 추가, 대부분의 LLM에서 사용 (GPT)- Wordpiece Tokenizer : 각각 나올 확률보다 쌍으로 나올 확률이 높으면 추가 (BERT)- Unigram Tokenizer : 최선의 조합을 찾고 쓸모 없는 것은 버림, 확률에 따라 토큰화 결과가 매번 다름, 속도가 느림 (T5)Embedding : 어떤 데이터를 벡터로 표현한 것벡터공간 : 단어간 의미 계산 가능위치인코딩 : 토큰에는 단어의 위치 정보가 없지만 단어는 위치에 따라 의미가 달라짐- 절대 위치 인코딩 : 단어의 위치를 절대값으로 표기	- Sinusoidal Positional Encoding : 짝수 sin, 홀수 cos, 서로다른 주기를 활용해 수만 단어 길이의 문장에서도 유일한 위치 지문 생성 가능- 상대 위치 인코딩 : 단어 사이의 거리를 임베딩, 매 스텝마다 값이 변해서 KV캐싱이 어렵고 속도가 느림- ROPE : 벡터 회전으로 단어의 위치를 임베딩, 절대/상대 위치 인코딩의 장점을 융합, 현재는 대부분 ROPE를 사용해 위치 임베딩Text 생성 : 다음 단어를 반복적으로 예측(Autoregressive), 한 스텝마다 토큰 하나 예측Token화 : 데이터셋을 Token으로 변경Special Token : 모델을 제어하고 입출력 구조를 정의하는 제어 신호- 문장 시작끝, 패딩, 질문 시작, 답변 시작, 프롬프트, CoT, 파일 경계 구분, 외부 도구 호출 등등데이터셋 : Self-Supervised - Label 없이 생성, 사람이 답을 주지 않고 학습, 타겟의 위치를 항상 한 칸 더 shifting 해서 생성Token 임베딩 : Token id를 연속 벡터 공간의 점으로 맵핑6. Attention문맥을 파악, 연관되어 있으면 값이 크게 나타남Self Attention, Cross Attention ...Embedding에서 weight를 곱해서 Q(질문), K(대상), V(속성)을 구함- 내적의 특징 때문에 Q와 K가 분리되어있어야 Attention이 제대로 동작할 수 있음 - K와 V를 분리하지 않으면 의미가 섞일 수 있음다음에 올 단어를 예측하는 것을 학습함으로써 Attention Score가 의미를 가짐Attention Score- 연관되어있으면 값이 커짐- Q와 K를 내적해서 계산- QK^T에 softmax 취하면 Attention Weight..?- Attention Weight와 Value를 곱하면 context vector가 나옴Attention의 의미 : 문맥의 의미를 더해서 새로운 문맥의 의미를 만듦Softmax : 어떤 숫자의 나열을 확률분포로 변환Masking : 현재 토큰이 미래 토큰을 보지 못하도록 Attention Score를 가림 (Causal Attention..?)Multi-head Attention : 각각의 head가 다른 관점에서 문맥을 파악함 (병렬)7. GPT : LayersDropout- softmax 통과 이후 랜덤으로 마스크를 만들어서 씌움, 계산 결과를 가리는 역할, 일종의 데이터 증강 역할을 수행해서 오버피팅 방지- 최근에는 데이터가 넘쳐나기 때문에 base 모델을 학습할 때는 잘 사용하지 않음, fine tuning 할 때는 사용정규화- 평균 0, 표준편차 1이 되도록 변환- 한쪽으로 쏠리지 않게 해서 학습을 안정화 시킴- 과도한 정규화는 학습 내용을 사라지게 할 수 있음, 감마/베타 스케일 상수를 적용해서 필요할 때만 정규화 (이것도 학습 가능)- Layer Normalization(LLM), Batch Normalization(비전)- RMS Normalization : 평균을 계산하지 않고 정규화Feed Forward Network : 차원 확장 -> 활성화 함수 -> 차원 감소 구성활성화 함수 : 비선형성 부여- Sigmoid : 처음 시도된 활성화 함수, 복잡한 패턴 학습 가능하게 함, 레이어가 깊어질수록 역전파 과정에서 사라지는 문제 - ReLU : 레이어를 깊게 쌓을 수 있게 만든 활성화 함수, 음수가 들어오면 다음 노드에서 전부 다 비활성화되는 문제- GELU : x=0 이하에서 살짝 음수로 내려갔다가 0으로 수렴, ReLU보다 안정화된 학습 가능- Swish : 베타값으로 게이트의 민감도 조절, 베타가 1일 때는 GELU와 비슷한 모양- GLU : 두 선형 함수로 구성, 앞쪽 선형함수에 시그모이드 취해서 게이트로 사용- SwiGLU : Swish + GLUResidual connection- Skip connections : 입력값과 출력값을 더해서 다음 레이어에 연결, 레이어 통과할 때마다의 출력값이 크게 변하지 않게 함- 변화량만 학습하면 되니까 학습이 쉬워서 깊은 레이어에서 안정된 학습 제공8. GPT 모델 입출력 ★Transformer 모듈의 입출력 차원이 동일 -> 모듈을 계속 쌓기 위함, Residual connection 가능하도록 하기 위함어텐션 및 피드포워드 다음에 잔차 연결을 위해 차원을 맞춰줘야함마지막 출력 층에선 차원이 달라짐, 하나가 shift된 출력 임베딩이 무슨 토큰인지 알아내야 하니까 임베딩 차원에서 토큰 갯수만큼의 차원으로 변함소프트맥스 함수를 활용해 로짓을 확률 분포로 변환하고 가장 높은 확률이 찾으려는 토큰항상 높은 것만 고르면 결정적이고 반복적이기 때문에 샘플링 기법 사용- Temperature(T) : Softmax에서 지수를 T로 나눔, T가 높으면 낮은 확률을 가진 토큰들의 값이 커지고 선택될 가능성이 커짐- Top-K 샘플링 : 확률이 높은 상위 k개의 토큰만 후보로 제한한 뒤, 그 후보들 중 확률에 따라 하나를 샘플링9. 지식의 저장FFN에서의 지식의 저장은 직교하는 벡터가 많아야한다N차원에서 직교하는 벡터는 N개 뿐 -> 89~91도까지 허용하면 고차원일수록 직교하는 벡터가 대다수 (차원이 커질수록 직교하는 벡터는 지수적으로 증가)직교성과 특징 분리 : 개념들이 서로 간섭하지 않도록 함직교하는 벡터가 많을 수록 넓은 공간을 활용하고 많은 정보를 담을 수 있다10. 모델 학습 ★Dataset : training, validation(overfitting 방지), test (7:2:1)학습과정 : 순전파 - 오차 계산 - 역전파 - 가중치 업데이트Loss 함수- MSE : 예측값과 실제값의 차이를 측정- Cross Entropy : Binary 분류에 사용경사하강법 : optimizer에 의해 수행Adam optimizer- 모멘텀과 속도를 추정해서 최적화- 과거의 기울기 변화량을 추정하여 매 스텝마다 방향이 크게 흔들리지 않게 한다- 기울기가 완만하면 크게 가고, 기울기가 가파르면 짧게 가도록 조절Epoch : 전체 데이터를 1회 학습 하는 것Step : 파라미터를 1회 업데이트 하는 것Batch size : 1스텝에서 사용하는 데이터 개수 (키우면 1epoch가 빠르게 도달 -> 학습 속도 빨라짐)11. Fine-tuning ★스팸 분류 미세 튜닝 예제- input이 짧은 경우 패딩, target은 0,1로 라벨링- 분류를 위해 마지막 layer 출력 차원을 토큰 개수만큼이 아니라 0, 1 2차원으로 수정- 결과는 softmax 후 argmax로 선책LoRA : 기존 모델은 고정하고 작은 저랭크 행렬만 학습하는 효율적인 파인튜닝 기법- 그래디언트와 옵티마이저 스테이트를 줄임- A, B 행렬로 전체 행렬고 동일한 크기 생성 AxB = LoRA weight- 원본 weight와 LoRA weight를 더해서 파인튜닝- 학습 시 LoRA weight만 업데이트- A는 랜덤으로 초기화, 행렬 B는 0으로 초기화 -> LoRA weight는 0으로 초기화QLoRA  : LoRA에 더해서 model weight 메모리까지 줄임, GPU 메모리가 부족할 때 사용BF16 : 지수항은 FP32와 같으나 수를 표시하는 bit가 작음12. 지시 미세 튜닝Prompt Format : 스페셜 토큰을 활용한 템플릿 활용입력패딩, 타겟패딩, 타겟 마스킹, 인스트럭션 마스킹RLHF or DPO : AI에게 인간이 무엇을 더 좋아하는지 채점(Feedback) 해주며 가르치는 학습 방식PPO- reward model을 통해 응답을 평가해서 fine tuning함- 모델이 4~9개의 여러 답변을 생성하면 사람이 답변 순위 결정하고 승패 쌍으로 변환해서 점수화DPO : 강화학습 과정과 별도의 reward model 없이 데이터만으로 사람의 선호도를 직접 학습Dataset구조- Reward model : Prompt, Response, Reddback(Rating)- DPO : Prompt, Chosen, Rejected============================ 시험 범위 ============================13. 추론 모델GRPO loss14.
